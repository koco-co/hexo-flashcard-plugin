## 产品定位与范围

本产品是面向 Hexo 博客的薄闪卡插件。作者在文章中显式声明问答、填空和选择卡；读者可以在文章内翻看卡片，也可以通过宿主站点中名称为 `复习` 的可见入口进入 `/learn-topic/`，使用严格单向队列复习。卡片解析、静态页面生成、浏览器队列和本地持久化由插件负责，间隔重复调度统一委托成熟依赖 `ts-fsrs`。

本版包含三段式卡片声明、按稳定 ID 跨文章引用同一卡片、文章内自适应翻转卡、可点击卡组与标签筛选、到期旧卡和新卡分离、四档动态 FSRS 评价、严格不可回退的会话快照、今日完成状态与本地进度重置。不包含账号、云同步、跨设备同步、复习历史修改、自由浏览模式、参数训练或高级统计。

## 产品现状与目标

Butterfly 的 `hideToggle` 与 Tag Plugins Plus 的 `folding` 只负责内容展开和折叠，不具备稳定卡片身份、跨文章筛选、复习队列或调度状态。本插件只处理显式 `flashcard` 定义和 `flashcard_ref` 引用，不改写现有标签、主题源码、主题菜单或主题配置；宿主集成方负责把插件生成的复习页接入站点现有导航。

目标是让纯静态 Hexo 站点形成“作者声明 → 构建校验 → 文章翻卡 → 到期复习 → 四档评价 → FSRS 安排下次复习 → 当前浏览器恢复”的完整闭环，同时让插件保持薄且可复用。

## 跨域用户旅程

作者用 `--- question`、`--- answer`、`--- explanation` 三段声明卡片，为卡片提供稳定 ID、单一卡组和可选多个标签。其他文章用 `{% flashcard_ref id="http-404" %}` 引用该 ID，不复制题目内容；引用继承原卡内容、卡组、标签和同一份进度，并计入引用文章的编号、文章筛选和“复习本篇”数量。构建失败必须指出来源、卡片 ID、字段或引用原因。有效卡片在文章中按 `Q01`、`Q02` 自动编号并以真实翻转卡展示；卡组和标签都带 `#` 且可点击进入筛选后的复习页。宿主站点在桌面导航和移动端菜单中提供名称为 `复习` 的入口，目标为 `/learn-topic/`。

进入复习页后，系统先应用 article、deck 或 tag 筛选，再从范围内截取 `due <= 当前时间` 的旧卡形成不可变会话快照。正面只显示问题和“点击查看答案”；翻面后显示 `问题:`、`回答：`、`解析：` 和四档动态预测。评价后立刻把卡片移出本次会话并自动进入下一张，不提供上一张、下一张或可回退位置。

到期旧卡为空时显示独立空状态，并允许用“开始学习新卡 N”启动从未学习的卡片。新卡与到期旧卡不合并计数。队列完成后显示确认文案和四档只读统计。每次预测和提交都调用同一组 `ts-fsrs` 参数，结果保存到当前浏览器。

## 全局输入与输出约定

- 只有显式 `flashcard` 定义和 `flashcard_ref` 引用进入学习系统；`hideToggle`、`folding` 和普通正文保持原行为。
- 每张卡必须有全站唯一且长期稳定的 ID；卡片内容修改但 ID 不变时继续关联原进度。
- `flashcard_ref` 只接受既有卡片 ID，不复制或覆盖原卡内容；同一卡片可以关联多篇文章，但全站复习池和本地进度仍只有一份。
- 引用计入所在文章的自动编号、文章筛选和“复习本篇”数量；同一文章重复引用同一 ID 时只渲染和计数一次。
- 每张卡必须有非空 question、answer 和 explanation；选择卡另需至少两个选项及正确选项键。
- `deck` 是单一主卡组，`tags` 是逗号分隔的多个标签；二者都能生成严格筛选入口。
- 文章复习入口数量、今日完成数、待复习数和四档间隔都必须来自真实运行时数据。
- 复习页的默认公开路径是 `/learn-topic/`，页面 H1、浏览器标题、桌面导航和移动端菜单名称统一为 `复习`；筛选参数支持 `article`、`deck` 和 `tag`。
- 插件负责生成复习页，不自动修改宿主主题；宿主集成方必须显式提供可发现的站点入口。
- 核心学习不调用账号、云端 API 或 CDN；`ts-fsrs` UMD 资源由插件作为本地静态资源生成。

## 全局交互与文案原则

| 状态 | 最终文案 |
| --- | --- |
| 页面名称 | `复习` |
| 文章入口 | `复习本篇 · N 张卡片` |
| 会话标题 | `今日复习` |
| 会话进度 | `已完成 N · 待复习 N` |
| 正面提示 | `点击查看答案` |
| 背面结构 | `问题:`、`回答：`、`解析：` |
| 评价提示 | `这张卡记得如何？` |
| 四档评价 | `忘记`、`模糊`、`记得`、`简单` |
| 动态间隔 | `N 分钟后` 或 `N 天后` |
| 无到期卡 | `待复习 0`、`暂无到期卡片`、`你可以去学习新卡，或稍后再来`、`开始学习新卡 N` |
| 完成 | `今日复习已全部完成`、`共复习 N 张卡片，明天再见 👋`、`查看今日复习统计` |
| 清除确认 | `清除后无法恢复当前浏览器中的学习进度。` |

以上产品文案是已确认合同，不使用近义改写；卡片类型文案固定为 `问答`、`填空`、`选择`。

## 跨功能产品要求

- 学习闭环必须在纯静态托管、无账号和无外部学习服务的条件下可用。
- 插件样式继承宿主主题变量，并提供通用降级值；不得直接依赖或修改 Butterfly 源码。
- 翻面高度随富文本、表格、代码、图片和链接自适应；桌面文章卡最多两列，移动端单列，复习页单卡居中。
- 文章内自适应小卡的 `问题:`、`回答：`、`解析：` 与各自内容分行；复习页独立大卡的三个标签与内容保持同行，只在内容自然溢出时换行。
- 前端支持首次加载与 `pjax:complete` 幂等初始化、键盘翻面、明暗主题和 reduced-motion。
- 宿主集成验收同时覆盖桌面导航、移动端菜单、点击进入复习页和 PJAX 往返；只有路由可直接访问不算入口完成。
- `ts-fsrs` 预测与提交必须使用相同时间点、相同参数和关闭 fuzz 的确定性配置，避免按钮显示与实际到期时间不一致。
