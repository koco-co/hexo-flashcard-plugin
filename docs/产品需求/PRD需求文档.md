## 产品定位与范围

本产品是面向 Hexo 博客的薄闪卡插件。作者在文章中显式声明问答、填空和选择卡；读者可以在文章内翻看卡片，也可以通过宿主站点中名称为 `复习` 的可见入口进入 `/learn-topic/`，使用严格单向队列复习。卡片解析、静态页面生成、浏览器队列和本地优先持久化由插件负责，间隔重复调度统一委托成熟依赖 `ts-fsrs`；宿主可选接入 Supabase 和 GitHub 登录，为读者提供跨设备同步。

本版包含三段式卡片声明、按稳定 ID 跨文章引用同一卡片、文章内自适应翻转卡、可点击卡组与标签筛选、今日练习/新卡练习/随机练习分离、每日新卡 50 张上限、四档动态 FSRS 评价、严格不可回退的会话快照、轻量学习仪表盘、按 FSRS 结果生成的月历复习计划、按日分页加载问题、每日打卡圆环、今日完成状态、本地进度重置，以及可选的 GitHub 登录和 Supabase 跨设备同步。支持把文章复习入口增强为与宿主赞助操作并排的“图标 + 复习”按钮；不包含手工制定学习计划、新卡日期排期、邮箱密码账号、多登录提供商、补签或复习历史修改、自由浏览模式、参数训练或高级统计。

## 产品现状与目标

Butterfly 的 `hideToggle` 与 Tag Plugins Plus 的 `folding` 只负责内容展开和折叠，不具备稳定卡片身份、跨文章筛选、复习队列或调度状态。本插件只处理显式 `flashcard` 定义和 `flashcard_ref` 引用，不改写现有标签、主题源码、主题菜单或主题配置；宿主集成方负责把插件生成的复习页接入站点现有导航。

目标是让纯静态 Hexo 站点形成“作者声明 → 构建校验 → 文章翻卡 → 到期复习 → 四档评价 → FSRS 安排下次复习 → 本地立即恢复 → 登录后跨设备合并”的完整闭环，同时让插件保持薄且可复用；未配置云端或未登录时，全部学习能力仍独立可用。

## 跨域用户旅程

作者用 `--- question`、`--- answer`、`--- explanation` 三段声明卡片，为卡片提供稳定 ID、单一卡组和可选多个标签。三段均支持 Markdown 围栏代码；插件为代码提供自包含的语言、行号、三色状态点、复制和折叠工具栏。其他文章用 `{% flashcard_ref id="http-404" %}` 引用该 ID，不复制题目内容；引用继承原卡内容、卡组、标签和同一份进度，并计入引用文章的编号、文章筛选和文章复习入口数量。构建失败必须指出来源、卡片 ID、字段或引用原因。有效卡片在文章中按 `Q01`、`Q02` 自动编号并以真实翻转卡展示；卡组和标签都带 `#` 且可点击进入筛选后的复习页。宿主站点在桌面导航和移动端菜单中提供名称为 `复习` 的入口，目标为 `/learn-topic/`；含卡文章在宿主赞助操作旁显示“图标 + 复习”入口，完整的“复习本篇 · N 张卡片”保留为提示与无障碍名称。

进入复习页后，系统先应用 article、deck 或 tag 筛选，再分别构建今日练习、新卡练习和随机练习队列。今日练习从当天任务快照中截取尚未完成的卡片；新卡练习只取未复习卡，按高频、中频、低频优先，每个 Asia/Shanghai 自然日最多首次开始 50 张；随机练习随机排列当前范围。当天计划的题数与今日练习队列必须来自同一批任务，不能出现计划显示 6 题而队列显示 0 题。正面只显示问题和“点击查看答案”；翻面后显示 `问题:`、`回答：`、`解析：` 和四档动态预测。评价后立刻把卡片移出本次会话并自动进入下一张，不提供上一张、下一张或可回退位置；只有今日练习评价影响每日打卡，新卡练习和随机练习不影响打卡。

三个模式始终独立显示并可切换：今日练习使用“今日练习（剩余 N）”，新卡练习使用“新卡练习（剩余 N）”，随机练习使用“随机练习”。随机练习和新卡练习的评价仍按同一组 `ts-fsrs` 参数更新后续计划，但不计入当天计划完成数。队列完成后显示当前模式的确认文案和四档只读统计。每次预测和提交都调用同一组 `ts-fsrs` 参数，结果先保存到当前浏览器。复习页只先加载轻量卡片索引；当前会话只渲染一张卡并预取下一张。当前筛选范围内已复习卡片的 `due` 和每日任务按 Asia/Shanghai 日期汇总到月历，主页不显示问题正文；点击日期后，当日问题每批最多加载 20 题。评价完成后月历数量和当日打卡状态立即更新。

宿主启用云同步后，读者可以选择使用 GitHub 登录。登录前仍为纯本地模式；登录后插件异步把本地进度与 Supabase 合并，卡片冲突由较大的 `last_review` 决定，每日任务和完成历史取并集。断网或云端失败不阻塞评价，也不删除本地记录；恢复联网后自动重试。退出登录保留本地进度。登录状态下重置要求输入固定文本 `重置`，数据库先递增重置版本并删除云端记录，成功后才清空本地，以阻止旧设备恢复已删除进度。

## 全局输入与输出约定

- 只有显式 `flashcard` 定义和 `flashcard_ref` 引用进入学习系统；`hideToggle`、`folding` 和普通正文保持原行为。
- 每张卡必须有全站唯一且长期稳定的 ID；卡片内容修改但 ID 不变时继续关联原进度。
- `flashcard_ref` 只接受既有卡片 ID，不复制或覆盖原卡内容；同一卡片可以关联多篇文章，但全站复习池和本地进度仍只有一份。
- 引用计入所在文章的自动编号、文章筛选和“复习本篇”数量；同一文章重复引用同一 ID 时只渲染和计数一次。
- 每张卡必须有非空 question、answer 和 explanation；选择卡另需至少两个选项及正确选项键。
- `deck` 是单一主卡组，`tags` 是逗号分隔的多个标签；二者都能生成严格筛选入口。
- 文章复习入口数量、今日完成数、待复习数、四档间隔和未来复习计划都必须来自真实运行时数据。
- 复习页的默认公开路径是 `/learn-topic/`，页面 H1、浏览器标题、桌面导航和移动端菜单名称统一为 `复习`；筛选参数支持 `article`、`deck` 和 `tag`。
- 插件负责生成复习页，不自动修改宿主主题；宿主集成方必须显式提供可发现的站点入口。
- 核心学习在未配置同步或未登录时不依赖账号和云端 API；`ts-fsrs` 与可选 `supabase-js` UMD 资源都由插件作为站点本地静态资源生成，不依赖第三方 CDN。

## 跨功能产品要求

- 学习闭环必须在纯静态托管、无账号和无外部学习服务的条件下可用；云同步只是可选增强。
- 每次评价必须先同步写入 localStorage，再异步上传；云端请求失败、离线、登录失效或 OAuth 取消都不得回滚、覆盖或删除刚保存的本地进度。
- 新卡练习首次展示未复习卡时记录 `newCardDays`，按稳定卡片 ID 去重；新卡练习与随机练习不创建或完成每日打卡任务。
- 新卡练习按 `priority:1`、`priority:2`、`priority:3` 顺序取未复习卡，每个 Asia/Shanghai 自然日最多首次开始 50 张；已开始但未完成的卡可以继续。
- 云端表必须启用 RLS，匿名角色不能读写进度或调用同步 RPC；登录角色只能访问 `auth.uid()` 对应的数据，浏览器只使用 Supabase publishable key。
- 同步以数据库事务执行：卡片按稳定 ID 比较 `last_review`，时间较大的状态胜出；每日任务按日期和卡片 ID 取并集，完成时间保留非空且较新的值。
- 全局重置使用单调递增的重置版本作为墓碑；版本落后的设备必须采用云端快照并丢弃旧本地快照，不能重新上传已重置数据。
- 插件样式继承宿主主题变量，并提供通用降级值；不得直接依赖或修改 Butterfly 源码。
- 浅色模式下，文章卡、复习卡及其关联卡面统一使用低饱和青蓝—中性—淡粉渐变；选项使用半透明中性色承载文字。深色模式继续继承宿主主题的深色卡片背景。
- 复习页使用轻量学习仪表盘层次，利用状态头、真实会话进度线、状态图标光晕和卡片层次强化信息结构；“已完成”与“待复习”使用无大面积背景的轻量双指标表达，不使用厚重灰白胶囊。
- 复习计划位于当前复习状态下方，以月历展示每日数量和打卡圆环；绿色渐变圆环表示当日全部按时完成，红色渐变圆环表示当日有题未完成，未来日期和无题日保持中性。
- 点击日期后的问题抽屉每批最多渲染 20 题；日期、时间、卡组、标签和问题必须可读，长问题、深色模式和移动端不得溢出。
- 复习页 HTML 不嵌入全量问题、回答、解析和选项正文；运行时通过轻量索引与本地卡片内容分片按需读取。
- 过去未完成的打卡保留红色；次日补做只能完成次日队列，不提供补签，不追溯改写前日历史。
- 宿主存在赞助操作时，文章复习入口迁移到其旁边并匹配按钮尺寸、颜色与圆角；悬浮时按钮上浮、阴影增强且图标摆动，悬浮或聚焦复习入口不得展开赞助内容。宿主没有赞助操作时保留原文章入口作为降级。
- 文章卡与复习卡在桌面和移动端都以单列占满各自父容器；翻面高度随问题、选项、回答、解析、表格、代码、图片和链接自适应。
- 围栏代码默认展开，深色代码区显示语言、行号、三色状态点、复制和折叠控件；复制只取源代码，折叠只隐藏代码正文，代码点击、选择和横向滚动均不得触发卡片翻面。
- 代码工具栏由插件幂等初始化，不依赖 Butterfly；文章卡、动态复习卡、PJAX 返回、移动端、深色模式和 reduced-motion 使用同一行为合同。
- 文章内自适应小卡的 `问题:`、`回答：`、`解析：` 与各自内容分行；复习页独立大卡的三个标签与内容保持同行，只在内容自然溢出时换行。
- 复习卡背面的 `问题:`、`回答：`、`解析：` 使用相同标签列、间距和正文起点；选择题的问题与选项组使用同一左侧轴线，选项文字在选项行内垂直居中，问题与选项作为一个内容组垂直居中。
- 前端支持首次加载与 `pjax:complete` 幂等初始化、键盘翻面、明暗主题和 reduced-motion。
- 宿主集成验收同时覆盖桌面导航、移动端菜单、点击进入复习页和 PJAX 往返；只有路由可直接访问不算入口完成。
- `ts-fsrs` 预测与提交必须使用相同时间点、相同参数和关闭 fuzz 的确定性配置，避免按钮显示与实际到期时间不一致。
